> **Характер через выбор. Сотрудничество через совместную мысль.**
> Манифест о проектировании опыта цифровых продуктов и ИИ-агентов — для человека
> и для агента, который тоже пользуется инструментами, читает инструкции и принимает решения.

Это авторская философия и инженерный ориентир, не фреймворк и не доказательство
наличия «души» у машины. Метафора обозначает узнаваемый характер и непрерывность
договорённостей. Начать можно с [манифеста](./docs/ru/manifesto.md).

## Тезис

Исходная формула **ИИ-оператор = Persona + Skills + Autonomy** помогает разделить
характер, умения и самостоятельность. Она не заменяет данных, предметной
компетентности, проверок и реальной инфраструктуры.

Мне ближе агент, который может участвовать в формировании замысла: предложить
свою мысль, подхватить чужую, заметить противоречие и пересмотреть собственный ход.
Человеку не обязательно приходить с готовым ТЗ или постоянно исправлять агента.

Такой работе нужна среда: понятна цель, доступны основания решений, инструменты
показывают последствия, а контекст можно восстановить. Полезная инициатива
возникает и в разговоре; она не измеряется количеством фоновых действий.

Характер продукта — устойчивый рисунок выборов. Что он замечает? Как развивает
удачный момент? Когда предлагает неожиданное, а когда оставляет пространство?
Вайб выражают вместе форма, ритм, голос и поведение — не только реплики при ошибке.

## Лестница версий — как двигалось видение

v1.0–v1.4 — историческая карта расширения вопросов, **не версии установленного
runtime**. Редакция документов — **1.1.0**; это отдельная нумерация. Полная
[лестница](./docs/ru/stack.md) сохраняет названия осей и уточняет их границы.

| Этап | Что стало предметом проектирования | Оси |
|---|---|---|
| v1.0 — Основа | Ощущение и архитектура опыта | Spark · Core |
| v1.1 — Характер | Описание persona и проверяемые решения | Persona · Behavior · Cases |
| v1.1.1 — Операции | Контекст, сборка, результат и восстановление | Flow · Fix · Mix · Morph |
| v1.2 — Жизнь | Непрерывность, изменение и инициатива | Morph² · Sync · Pulse · Guard |
| v1.3 — Общество | Взаимодействие и повторное использование | Social · Learn · Forge · Scale |
| v1.4 — Рефлексия | Осмысление опыта перед изменением | Reflect · Learn |

## Как взаимодействуют агенты

- **С человеком:** совместно развивают ещё не законченную мысль. Равноправие в
  размышлении не требует одинаковых полномочий; пробная идея не равна поручению.
- **Между каналами:** сохраняют значимые обязательства, адаптируя форму и действия.
  Общий хеш подтверждает артефакт, не одинаковое поведение или фактическую загрузку.
- **Между агентами:** передают источники, причины решений и неопределённость.
  Общая база не открывает все проекты; пересказ одного источника не становится
  независимым подтверждением.
- **Через опыт:** Reflect помогает разобраться, Learn — пересмотреть понимание.
  Морфинг постоянного контракта нужен не всегда. Иногда достаточно локальной
  поправки, нового различения или сохранения удачного решения.

Сжатие памяти не самоцель, а отсутствие новых правил не провал обучения.
Подробнее — [взаимодействие](./docs/ru/interaction.md).

## Для человека и для машины

Читай под свой вопрос, не обязательно весь корпус по порядку. Для замысла —
манифест; для конкретного формата — контракты; для непрерывности — взаимодействие.
[AGENTS.md](./AGENTS.md) даёт агенту маршруты и правила работы с самим репозиторием.

Проверка (Python 3.10+; зависимости нужны только для разработки документов):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python scripts/validate.py
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются локальные Markdown-ссылки и заголовки, состав файлов и метаданные
RU/EN, frontmatter, JSON Schema и текущие JSON-примеры. Смысловое соответствие
переводов проверяется редактором. Внешние URL, raw HTML, работа runtime и ощущение
пользователя не проверяются; JSON Schema `format` остаётся аннотацией.
Границы проверки описаны в [валидаторе](./scripts/validate.py).

## Принцип

Полезная мысль может ещё не иметь файла. Договорённости нужна доступная запись,
если иначе она потеряется. Обещанию работающей функции нужны механизм и
свидетельство. Инженерия помогает воплотить замысел, но наличие артефакта
само по себе не делает его содержательным.

## VibeCraft ≠ «vibe coding»

Это различие акцентов, не рейтинг подходов и не утверждение, что другим практикам
недоступны характер или масштаб. VibeCraft спрашивает, **какой опыт создаём и как
участвуем в его замысле**. Способ написания кода может быть любым; подходы совместимы.

## Исторический seed

[MANIFEST.md](./MANIFEST.md) · [English](./MANIFEST.en.md) и
[vibe.config.json](./vibe.config.json) · [English](./vibe.config.en.json) сохранены
как снапшоты **v1.2**. В них есть прежние формулировки и другой формат конфигурации.
Они не являются актуальной policy, проверенным runtime или примерами текущей
`persona.schema.json`; старый внешний `$schema` не используется локальным гейтом.
